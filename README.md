# Bora — treino em casa

App da família para o desafio de 30 dias de treino em casa. Funciona no celular, sem internet, sem cadastro e sem pagar nada.

**Abrir e instalar:** https://wilmer-ly.github.io/repositorio-teste/
No Chrome do celular: menu ⋮ → **Instalar app** (ou **Adicionar à tela inicial**).
